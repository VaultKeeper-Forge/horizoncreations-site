# Horizon Apps And Receipts

This folder holds support material for partnership research, creator-app prep, and other Horizon side systems that are not part of the public site build.

## What belongs here

- browser prep screenshots
- contract / terms receipts
- creator application reference images
- other app-side research assets worth keeping with the repo

## What does not belong here

- live site gallery photos
- local one-off intake drops from the phone
- generated build output

## Layout

- `reference-receipts/`
